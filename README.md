# unit-d10-biomechanics-engine
Unit D-10 240Hz Three.js WebGPU quadruped biomechanics engine with 6-DOF rigid-body physics, 4-leg ground reaction forces, 3D IK with 4-bar hind pantograph, walk/trot/gallop gaits, dynamic lumbar spine bending, and recoil-responsive railgun, head, ear, and tail physics.
